# ContractCheck Live Ready

هذه نسخة جاهزة للنشر كرابط ويب.
- PDF وDOCX
- رفع الملف
- استخراج النص
- تحليل OpenAI
- نتيجة منظمة باللغة العربية
- تعمل كـExpress app ويمكن نشرها على Vercel.

## النشر
1. ارفع المجلد إلى GitHub.
2. اربطه بـVercel.
3. أضف Environment Variable:
   OPENAI_API_KEY = مفتاح OpenAI الخاص بك
4. Deploy.
5. افتح رابط Vercel واختبر عقد الـPDF.

Vercel يدعم نشر Express/Node.js، ويمكن ضبط متغيرات البيئة من إعدادات المشروع.
